# 프로필 초안 생성 API

현재 서버 경로는 `POST /api/builder/generate`이며 OpenAI Responses API의 JSON 구조화 출력과 SSE를 사용한다.

## 설정

현재 작업 폴더의 `.env.local`에 다음 환경변수를 등록한다. 실제 키는 Git이나 채팅에 올리지 않는다.

```dotenv
OPENAI_API_KEY=your-openai-api-key
OPENAI_MODEL=gpt-6-luna
```

환경변수 변경 후 개발 서버를 다시 시작한다. Vercel에서는 프로젝트 환경변수에 같은 이름을 등록하고 재배포한다.

Luna는 짧은 초안 생성에 맞춰 `reasoning.effort=none`으로 요청한다. 기존 모델을 환경변수로 지정하면 Luna 전용 추론 옵션을 보내지 않는다.

## 실제 확인 순서

1. 로그인 후 `/builder`에서 경험·역할과 성과·가치관과 톤을 입력한다.
2. 초안을 생성하고 한 줄 소개, 역량 3개, 프로젝트 요약, 조형 가이드가 표시되는지 확인한다.
3. AI 생성 성공과 계정 저장 성공을 각각 확인한다. API 키 미등록, 요청 거절, 지연 시 기본 템플릿으로 전환되므로 결과 표시만으로 AI 성공으로 판정하지 않는다.
4. 입력과 결과는 `ai_interview_sessions.answers`에 저장된다. 공개 프로필 발행이나 생성 문구의 직접 편집은 별도 기능이다.

## 2026-11-04 연결 준비 기록

- 기본 모델을 `gpt-4o-mini`에서 사용자가 선택한 `gpt-6-luna`로 변경했다.
- 타입 검사, 수정 API 파일 ESLint, 기존 `test-builder-draft.mjs` 통과.
- 로컬 API 키 미등록으로 실제 OpenAI 호출 및 AI 결과 저장은 이번 작업에서 확인하지 못했다. 키 등록 후 유료 API 호출과 스트리밍 완료·DB 저장을 확인해야 한다.

## 같은 날 API 키 등록 후 확인

- 사용자 로컬 키 등록 후 서버 재시작. 비밀값은 출력하지 않았다.
- Luna 최소 요청 HTTP 200, 실제 프로필 구조화 SSE 직접 요청 HTTP 200 및 Zod 검증 통과(약 3.4초 전체 응답, 첫 생성 토큰 시간은 미측정).
- 로그인된 웹의 3단계 입력부터 생성까지 가상 전시 기획 사례로 실행. 최초 호출은 기본 템플릿으로 전환됐으며 정확한 원인은 미확정이다. 동일 화면의 재생성에서는 실제 AI 생성·계정 저장 성공.
- DB 조회로 해당 테스트 초안의 `generation_source=openai`, `status=completed`, 역량 태그 3개를 확인했다. 테스트 기록은 AI 생성 1건·기본 템플릿 1건이며 테스트임을 제목에 표시했다.
- 화면은 AI 초안 결과를 표시한 상태로 두었다. 실제 경험 입력, 생성 문구 편집, 공개 프로필 발행, Vercel API 키 등록은 별도 작업이다.
