## 검증

- ESLint/TypeScript/프로덕션 Webpack 빌드 검사. 생성된 브라우저 번들 `test-artifacts`는 린트·Git 대상에서 제외했다.
- `scripts/test-builder-draft.mjs`: 단계 필수값/길이/키워드 상한/톤, 새로고침용 데이터 직렬화, 손상/과도한 입력 거부, payload 변환.
- `scripts/test-workshop-code.mjs`: 1000회 포맷, 충돌5회 성공·소진·비충돌 오류 재시도 방지.
- `supabase/tests/admin_workshops.sql`: 실제 개발 DB에서 admin 전역 조회/종료, participant/instructor/위조user_metadata 거부, 소유권 변경 거부, 소문자 검증·참가 컨텍스트, 정원·종료·만료·anon 차단. 전체 롤백.
- 기존 users RLS 시험의 프로비저닝·본인 조회/수정·타인/역할 승격/anon 차단 부분도 실제 DB에서 롤백 재검증했다. auth.users 삭제가 포함된 원본 전체 시험은 확인 만료로 실행되지 않아, 삭제 cascade 부분을 제외한 안전한 롤백 시험으로 확인했다. cascade 삭제는 이번 재점검에서 재실행하지 않았다.
- 실제 로그인 브라우저: 관리 화면 발급201 → 코드 복사 성공 → 소문자 입력 확인 → join → `/builder` → 2단계 텍스트 입력 후 새로고침 복원 → `/dashboard` 실제 워크숍 표시 → 관리자 종료 → join403/SESSION_EXPIRED. 관리자 계정으로 참여 흐름을 검증했으며, 별도 participant 역할 차단/허용은 DB 테스트에서 검증했다.
- 실제 브라우저용 검증 세션은 ID와 테스트 제목을 함께 조건으로 삭제했고 잔존0 확인. 해당 워크숍의 임시 입력도 제거했다.
- 컴포넌트 하네스(실제 컴포넌트+모의 컨텍스트): 1280px PC 사이드바,375px 모바일 탭·가로 넘침 없음, 오프라인 배너, 다른 계정의 초안 미노출, 손상 저장값 복구, 최종 콜백1회. 테스트 하네스는 src/app에 라우트를 만들지 않는다.

스크린샷은 Git에 포함하지 않는 `test-artifacts/`에 저장했다. `npm audit --omit=dev` 기준 배포 의존성 취약점은 0건이다. 개발 도구 포함 전체 설치에서는 moderate 안내가 있었으며 강제 업데이트는 수행하지 않았다.

## 상태 판단

입장·위저드 UI·관리자 코드 발급은 내부 검증 후 사용자 검토 대상으로 삼을 수 있다. 앱셸과 인증의 미검증 경로, 대시보드 실제 지표까지 포함한 전체 완료로 묶지 않는다. 완료(done)는 사용자 최종 검토 후 처리한다.

ign8t 상태는 입장·위저드 UI·관리자 발급을 review, 앱셸·인증·대시보드를 in_progress로 기록했다. 마지막 실제 인증 응답은 /api/auth/me 200, role=admin, profileSyncReady=true였고 검증 세션 제거 후 헤더가 ‘세션 미참여’로 표시되는 것도 확인했다.
