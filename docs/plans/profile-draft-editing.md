# 프로필 초안 편집·저장·재조회

관련 ign8t 작업: `55966c3d-c29e-428f-933f-f8510c58d507`

## 사용자 흐름

`/builder` 아래의 **내 말로 다듬기**에서 가장 최근에 저장한 본인 워크숍 초안을 불러온다. 개인 모드는 워크숍이 없는 본인 초안만 조회한다.

- 한 줄 소개, 역량 세 개, 프로젝트 요약을 클릭해 직접 편집한다.
- 단일 문구 Enter 확인, Escape 취소, 바깥으로 포커스를 옮기면 확인. 빈 문구는 기존 값으로 유지한다.
- **더 짧게** 또는 **톤 변경**으로 Luna 수정 제안을 받은 후 적용하거나 취소한다.
- 생성 원문으로 되돌린 뒤 저장할 수도 있다.
- **수정한 초안 저장**으로 계정에 보관하고, 화면을 다시 열면 수정본을 조회한다.
- 저장하지 않은 확정 편집은 현재 탭에 임시 보관하며 로그아웃 시 제거한다. 미저장·편집·AI 요청 중에는 새 초안 생성 버튼을 막아 수정 내용을 보호한다.

이는 비공개 인터뷰 초안 저장이며, 공개 프로필 발행은 별도 기능이다.

## 구현 구조

- `GET /api/builder/draft?workshopSessionId=<uuid>`: 서버 `getUser` 및 소유자 필터/RLS를 적용해 최신 완료 초안을 조회. 파라미터 생략 시 개인 초안만 조회.
- `PATCH /api/builder/draft`: 본인 초안만 수정. `updatedAt` 비교로 오래된 화면의 덮어쓰기를 409로 차단.
- `POST /api/builder/regenerate-block`: 인증 및 요청 출처 검사, 문구 길이 검증 후 선택한 블록만 AI로 전송. 재생성은 DB를 직접 변경하지 않으며 사용자가 적용·저장해야 반영.
- 기존 `ai_interview_sessions.answers.generated_draft` 원문 유지. `edited_draft`에 수정 가능한 세 필드만 저장. 원래 답변·조형 가이드·생성 출처 유지. 스키마·RLS 변경 없음.
- AI 설정은 서버 전용 `getProfileAiConfig`를 생성 API와 공유한다. 기본 모델 Luna, 추론 없음, 부분 재작성 출력 한도 200토큰.
- 서버 인스턴스별 메모리 제한: 사용자/IP당 분당 10회, 동일 문구 블록당 분당 5회. 분산 인스턴스 전체를 아우르는 제한은 아니다.
- 외부 AI 오류/시간 초과/검증 실패 시 기존 문구 유지 및 직접 편집 안내. 새 사실이나 성과를 만들지 않도록 지시하고, 줄이기는 35% 이상 감소 검증.

## 2026-11-04 확인 기록

- 기존 가상 전시 기획 테스트 초안에 소개 문구를 직접 입력하고 저장. 새로고침 및 API 재조회에서 동일 수정본 확인.
- DB 읽기 대조: 생성 원문 보존, 수정 소개 별도 저장, 요약 154자 → 50자 저장 확인.
- 실제 Luna로 요약 단축 제안 생성 → 적용 → 저장, 도전적 톤 제안 생성 → 취소 → 기존 문구 유지 확인.
- 초기 단축 제안이 길이 검증을 통과하지 못했을 때 기존 문구와 안내 유지 확인. 숫자로 목표 길이를 명시한 프롬프트로 보정 후 단축 성공.
- Enter 빈칸 방어 및 Escape 취소 확인.
- 비로그인 GET/AI 재작성 401, 외부 Origin PATCH 403, 잘못된 태그 개수 400, 없는 초안 404, 오래된 수정본 409 확인. 별도 타인 계정에 로그인한 교차 계정 API 검증 및 강제 제공자 타임아웃 시험은 미수행.
- `node scripts/test-builder-rate-limit.mjs`: 사용자 10회/블록 5회 제한, 키 격리 및 60초 만료 경계 통과.
- `node scripts/test-builder-draft.mjs`, `npx tsc --noEmit`, `npm run lint`, `npm run build -- --webpack` 통과. 빌드 25개 페이지 생성.
- 브라우저 320px/1280px에서 신규 편집 영역 스크린샷 및 가로 넘침 없음 확인. 새로 연 화면 콘솔 오류 없음.
- AI 수정 요청의 실제 성공 응답은 약 3.1초·5.3초. 스펙의 2초 목표는 미달이므로 성능 후속 검토 필요.
- 로컬 코드/개발 DB의 테스트 초안만 갱신. 커밋·푸시·Vercel 배포 미수행. ign8t는 검토 단계이며 사용자 검토 없이 완료 처리하지 않는다.
